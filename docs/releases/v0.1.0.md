# Mathom v0.1.0 — the archive opens

> *In the Shire, a "mathom" is anything you have no immediate use for but are
> unwilling to throw away — kept safe rather than tossed out.*

This is the first release of Mathom: a fully local, self-hosted home for the
voice messages that interrupt your day. Mathom transcribes them with
faster-whisper, summarizes them with Ollama, and shelves each one as a
searchable **Mathom** in your own archive. No cloud, no telemetry, no account
anywhere but yours.

It runs on a laptop, a NAS, or a TrueNAS SCALE box, in two containers.

## What you can do with it

**Bring recordings home.** Upload audio or video, paste text, or import TXT,
Markdown, PDF, and DOCX. On Android, install Mathom as a PWA and share a
WhatsApp voice message straight from the share sheet — the upload dialog opens
pre-filled, and the file goes from your phone to your server only.

**Get something useful out.** Twelve editable prompt templates — TL;DR, Meeting
Minutes, Action Items, Email Draft, GitHub/Jira Issue, CRM Entry, Calendar
Events, Executive Brief and more — produce summaries that stream in token by
token. Keep several per recording, edit them by hand, regenerate with a
different template, or delete the ones that missed.

**Ask follow-up questions.** Chat with any recording, grounded in its
transcript, with the conversation saved alongside it.

**Find it again later.** Full-text search (SQLite FTS5) across titles,
transcripts, summaries, and tags, with highlighted snippets — plus colored tags,
favorites, collections, an archive, a timeline, and filtering by source app.

**Take it with you.** Export any Mathom as Markdown, plain text, or JSON.

**In your language.** Summaries and chat answer in the transcript's detected
language, and the interface speaks English, German, and Spanish.

## Optional, and off until you ask

- **Local video visual analysis** — sampled still frames described by a local
  vision model, stored separately from the spoken transcript.
- **Speaker diarization** — timestamped speaker labels via a locally
  provisioned pyannote pipeline.
- **Multi-user with Authentik SSO** — private per-user archives, Owner/Admin/User
  roles, MFA delegated to your identity provider, and email invitations.

None of these download models or contact anything on their own.

## Install

Requirements: Docker with Compose v2. Optional: NVIDIA Container Toolkit for GPU
acceleration. Plan for a few GB of disk for the Whisper and Ollama models.

```bash
git clone https://github.com/MacNite/mathom.git
cd mathom
git checkout v0.1.0
cp .env.example .env      # defaults work
make up                   # CPU stack  (make up-gpu for NVIDIA)
make models               # pull the Ollama model, first run only
```

Then open **http://localhost:8080**.

Prefer the published image? Tagged releases are pushed to GHCR:

```
ghcr.io/macnite/mathom:0.1.0
```

## Before you expose it

Mathom ships closed by default, and the default is worth understanding:

- **Authentication is off, so the UI binds to `127.0.0.1`** — reachable only
  from the host. Setting `MATHOM_BIND=0.0.0.0` for LAN access removes the only
  thing standing between your archive and your network. Do it behind a VPN or an
  authenticating reverse proxy, or turn on SSO first.
- **Ollama never publishes a port.** It is reachable only on the internal
  Compose network.
- Uploads are validated by content as well as extension, size-capped, and stored
  under server-generated names; FFmpeg runs with fixed arguments and timeouts.
- Uploads, chat, summaries, search, and login are rate-limited per client.

Read the [exposure warning](../deployment.md#exposure-warning) and the
[threat model](../threat-model.md) before Mathom is reachable by anyone else.

## Known limitations

- **Transcription quality follows the model you choose.** The default
  `WHISPER_MODEL=small` on CPU is a compromise; `medium` or `large-v3` on a GPU
  is markedly better and markedly slower.
- **One recording is processed at a time.** A single worker thread drains the
  queue; uploads beyond `MAX_QUEUED_JOBS` (25) are rejected with `503` and a
  `Retry-After`.
- **Web Share Target is Android-only** — a platform limitation, not a Mathom
  one. On iOS, install the PWA and upload from within the app.
- **Visual analysis samples frames, it does not watch video.** Descriptions are
  approximate and can miss what happens between samples. It is not face
  recognition, tracking, or forensic analysis.
- **No app-store build**, by choice. Installing as a PWA keeps the connection
  between your phone and your server direct.
- **Backups are yours to schedule.** `scripts/backup.sh` snapshots the database
  and audio; nothing runs it for you.

## Upgrading

Nothing to upgrade from — this is the first release. From here on, schema
changes are additive and run automatically at startup, so upgrades are
`docker compose pull && docker compose up -d`.
